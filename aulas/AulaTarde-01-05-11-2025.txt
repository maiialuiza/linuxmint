# 🍷 WINE (Wine Is Not an Emulator)

### ✔ O que é
- Camada de compatibilidade que permite rodar programas e jogos de Windows no Linux.

### ✔ Vantagens
- Leve e rápido.
- Roda arquivos .exe e .msi.
- Altamente configurável.

### ✔ Desvantagens
- Pode exigir configuração manual.
- Nem tudo roda perfeitamente.

### ✔ Quando usar
👉 Quando você quer instalar programas ou jogos específicos do Windows e não se importa em configurar.

---

# 🎮 PlayOnLinux (POL)

### ✔ O que é
- Interface gráfica que facilita o uso do Wine.
- Permite múltiplos prefixos com versões diferentes do Wine.

### ✔ Vantagens
- Muito mais simples que configurar Wine manualmente.
- Cada programa usa sua própria versão do Wine.
- Ótimo para iniciantes.

### ✔ Desvantagens
- Menos atualizado que o Lutris.
- Algumas configurações são limitadas.

### ✔ Quando usar
👉 Quando você quer usar Wine facilmente, sem complicações técnicas.

---

# 🎮 Steam Proton

### ✔ O que é
- Versão otimizada do Wine criada pela Valve para rodar jogos de Windows dentro do Steam.
- Inclui DXVK, VKD3D, Esync, Fsync e outras otimizações.

### ✔ Vantagens
- Funciona automaticamente na maioria dos jogos.
- Melhor compatibilidade com games modernos.
- Atualizações frequentes.
- Usado no Steam Deck.

### ✔ Desvantagens
- Apenas para jogos do Steam.
- Anti-cheat pode causar problemas.

### ✔ Quando usar
👉 Quando você quer jogar jogos de Windows no Steam com o mínimo de configuração.

---

# 🔥 Qual usar para cada caso?

| Caso | Recomendado |
|------|-------------|
| Jogar jogos do Steam | **Steam Proton** |
| Jogar jogos fora do Steam (Epic, Battle.net, GOG) | **Lutris** ou PlayOnLinux, mas **Lutris recomendado** |
| Rodar programas comuns de Windows | **Wine** ou **PlayOnLinux** |
| Para iniciantes | **Proton (jogos)** e **PlayOnLinux (programas)** |


# 🧠 O que é e para que serve o Kernel-OEM (Linux)

**Kernel-OEM** é uma versão especial do kernel Linux, usada principalmente no **Ubuntu**, criada para oferecer **melhor suporte a hardware novo** e otimizações específicas para computadores produzidos por fabricantes (OEMs), como Dell, Lenovo e HP.

---

## ✅ O que é o Kernel-OEM?

É um kernel **customizado** que recebe:

- Drivers mais recentes  
- Correções antecipadas  
- Recursos novos antes do kernel padrão do Ubuntu  

Ele existe para dar suporte imediato a dispositivos recém-lançados.

---

## 🛠️ Para que serve o Kernel-OEM?

### 1. **Suporte a hardware recente**
Inclui drivers atualizados para:

- Placas Wi-Fi e Bluetooth modernas  
- GPUs Intel, AMD e NVIDIA novas  
- Trackpads, webcams e leitores biométricos  
- Controladores NVMe e PCIe recentes  

---

### 2. **Otimizações específicas para fabricantes**
O kernel-oem pode incluir ajustes de:

- Gerenciamento de energia  
- Controle térmico (ventoinhas)  
- Suspensão/hibernação  
- Desempenho em notebooks certificados

---

### 3. **Correções antecipadas de bugs**
Ele recebe patches antes do kernel padrão, resolvendo problemas que só seriam corrigidos nas versões futuras.

---

### 4. **Estabilidade em máquinas certificadas**
Muitos modelos empresariais certificados pela Canonical usam o kernel-oem por padrão.

---

## 🧩 Quando usar o Kernel-OEM?

Use se:

- Seu hardware é **muito novo**  
- Wi-Fi, áudio, touchpad, câmera ou GPU têm problemas no kernel padrão  
- Seu notebook é certificado com Ubuntu  
- Você precisa dos drivers mais recentes sem mudar a versão do Ubuntu

---

## ⚠️ Quando **não** usar?

Evite se:

- Está usando um **servidor**  
- Seu hardware já funciona perfeitamente  
- Prefere **estabilidade máxima** em vez de recursos novos  

---

## 📌 Resumo rápido

| Item | Kernel padrão | Kernel-OEM |
|------|---------------|-------------|
| Foco | Estabilidade | Suporte a hardware novo |
| Atualizações | Mais lentas | Mais rápidas |
| Público | Usuários gerais | Fabricantes e computadores novos |
| Drivers | Padrão | Mais modernos |
